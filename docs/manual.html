1โปรแกรมนี้ทำอะไร

โปรแกรมช่วยดึงข้อมูลงาน (Task) ทั้งหมดจาก ลิงค์แชร์สาธารณะของ ClickUp (เว็บ sharing.clickup.com) ออกมาเป็นไฟล์ Excel โดยอัตโนมัติ ได้ครบทุกข้อมูลในแต่ละ Task ไม่ใช่แค่คอลัมน์ที่เห็นในตาราง

  • ดึงได้ ทุก Field ของแต่ละ Task — รายละเอียดงาน (Description), สถานะ, ความสำคัญ, ผู้รับผิดชอบ, ป้ายกำกับ (Tags), วันที่ต่าง ๆ ฯลฯ
  • ดึง Comment ทั้งหมดในแต่ละ Task พร้อมชื่อผู้เขียนและวันที่
  • ดึง Subtask, Checklist และไฟล์แนบ (Attachments)
  • ไม่ต้อง Login, ไม่ต้องใช้ API Token, ไม่ต้องเป็นสมาชิก ClickUp
  • เป็นการ อ่านข้อมูลอย่างเดียว (read-only) ไม่มีการแก้ไขข้อมูลใน ClickUp
ต้องใช้ลิงค์แบบไหน? ลิงค์ต้องเป็นแบบ แชร์ View สาธารณะ ที่มีหลายงานอยู่ในนั้น เช่น

2การติดตั้ง (แบบง่าย — ใช้ไฟล์ .exe)

วิธีนี้เหมาะกับการนำไปใช้บนเครื่องอื่น ไม่ต้องติดตั้ง Python หรืออะไรเพิ่มเลย

1
คัดลอกไฟล์ clickup-scraper.exe ไปวางไว้ที่ใดก็ได้บนเครื่อง Windows ปลายทาง (เช่น Desktop หรือสร้างโฟลเดอร์ใหม่)
2
ดับเบิลคลิก ที่ไฟล์ clickup-scraper.exe เพื่อเปิดโปรแกรม
3
จะมี หน้าต่างสีดำ (Console) เด้งขึ้นมา และโปรแกรมจะ เปิดเว็บเบราว์เซอร์ให้อัตโนมัติ ที่หน้า http://127.0.0.1:5000
⚠️ Windows แจ้งเตือนความปลอดภัย? ครั้งแรกที่เปิด Windows อาจขึ้นหน้าจอ “Windows protected your PC” (SmartScreen) เนื่องจากไฟล์ยังไม่ได้เซ็นรับรอง — ให้กด “More info” แล้วกด “Run anyway” เพื่อเปิดโปรแกรม (เปิดได้ปลอดภัย เพราะเป็นไฟล์ที่เราสร้างเอง)
✔ หากหน้าต่างโดน Antivirus บล็อก ให้เพิ่มไฟล์ clickup-scraper.exe เป็นข้อยกเว้น (Exclusion / Allow) ในโปรแกรมแอนตี้ไวรัส ไฟล์ที่แพ็กด้วย PyInstaller บางครั้งถูกแจ้งเตือนเกินจริง

3การติดตั้ง (สำหรับนักพัฒนา — รันจากซอร์สโค้ด)

ใช้เมื่อต้องการแก้ไขโปรแกรม หรือสร้างไฟล์ .exe ขึ้นใหม่ — ต้องมี Python 3.13 บนเครื่อง

3.1 เตรียมระบบและติดตั้งไลบรารี

cd clickup-scraper
py -3.13 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt

3.2 รันโปรแกรม

.venv\Scripts\python.exe app.py

จากนั้นเปิดเบราว์เซอร์ไปที่ http://127.0.0.1:5000

3.3 สร้างไฟล์ .exe ขึ้นใหม่

ดับเบิลคลิกไฟล์ build_exe.bat หรือสั่ง:

.venv\Scripts\python.exe -m PyInstaller --noconfirm --onefile ^
  --name clickup-scraper --add-data "templates;templates" ^
  --collect-submodules openpyxl --hidden-import openpyxl.cell._writer app.py

ไฟล์ที่ได้จะอยู่ที่ dist\clickup-scraper.exe

4วิธีใช้งาน

1
คัดลอกลิงค์ Public Share จาก ClickUp
ใน ClickUp เปิด View ที่ต้องการ → กด Share → เปิด Public sharing → คัดลอกลิงค์ (ขึ้นต้นด้วย https://sharing.clickup.com/...)
2
วางลิงค์ลงในช่อง “ClickUp Public Link” บนหน้าโปรแกรม
3
(ไม่บังคับ) กดปุ่ม 👁️ ดูตัวอย่าง เพื่อตรวจสอบก่อนว่าจะได้กี่ Task / กี่ Comment
4
กดปุ่ม ⬇️ Export เป็น Excel → รอสักครู่ → ไฟล์ Excel จะถูก ดาวน์โหลดอัตโนมัติ (อยู่ในโฟลเดอร์ Downloads ตามปกติ)
5
ปิดโปรแกรม เมื่อใช้งานเสร็จ โดยปิดหน้าต่างสีดำ (Console) หรือกด Ctrl + C ในหน้าต่างนั้น
ใช้เวลานานไหม? ขึ้นกับจำนวน Task และ Comment — โดยทั่วไปหลักสิบ Task ใช้เวลาเพียงไม่กี่วินาที ระหว่างดึงข้อมูลปุ่มจะแสดงสถานะ “กำลังดึงข้อมูล...”

5ข้อมูลในไฟล์ Excel ที่ได้

ไฟล์ Excel 1 ไฟล์จะมี 5 ชีต (Sheet) แยกตามประเภทข้อมูล วันเวลาทั้งหมดแปลงเป็นเขตเวลาไทย (UTC+7) เรียบร้อยแล้ว

ชีตเนื้อหา
Tasks1 แถวต่อ 1 งาน — รหัส, ชื่องาน, สถานะ, ความสำคัญ, ผู้รับผิดชอบ, Tags, วันที่ทั้งหมด (สร้าง/แก้ไข/กำหนดส่ง/ปิดงาน), ผู้สร้าง, เวลาที่ประเมิน, จำนวน comment/ไฟล์แนบ/subtask, รายละเอียดงานแบบเต็ม, งานแม่, List/Project, ลิงค์เปิดงาน และ Custom Fields (ถ้ามี)
Comments1 แถวต่อ 1 ความคิดเห็น — งานที่เกี่ยวข้อง, ผู้เขียน, วันที่, ข้อความเต็ม, จำนวนการตอบกลับ, อีโมจิ (reactions)
Subtasksงานย่อยทั้งหมด พร้อมสถานะ ผู้รับผิดชอบ และกำหนดส่ง
Checklistsรายการเช็กลิสต์ในแต่ละงาน พร้อมสถานะติ๊กเสร็จ
Attachmentsไฟล์แนบทั้งหมด พร้อมชนิดไฟล์ ขนาด วันอัปโหลด และลิงค์ดาวน์โหลด

6ปัญหาที่พบบ่อย และวิธีแก้

อาการวิธีแก้
ขึ้นว่า “ลิงค์นี้ไม่ใช่ลิงค์ของ ClickUp” ตรวจว่าวางลิงค์ครบถ้วน และเป็นลิงค์จาก sharing.clickup.com
ขึ้นว่า “รูปแบบลิงค์ไม่ถูกต้อง” ต้องเป็นลิงค์แชร์แบบ View (มีหลายงาน) ไม่ใช่ลิงค์งานเดี่ยวหรือ Doc
ขึ้นว่า “ไม่พบ View นี้ หรือลิงค์หมดอายุ” ให้เจ้าของ View เปิด Public sharing อีกครั้ง แล้วคัดลอกลิงค์ใหม่
เบราว์เซอร์ไม่เปิดอัตโนมัติ เปิดเบราว์เซอร์เองแล้วพิมพ์ http://127.0.0.1:5000 (หรือดู Port ที่โปรแกรมแจ้งในหน้าต่างสีดำ)
Windows / Antivirus บล็อกไฟล์ .exe กด “More info → Run anyway” หรือเพิ่มไฟล์เป็นข้อยกเว้นในแอนตี้ไวรัส
ไฟล์ Excel ไม่ดาวน์โหลด ตรวจการตั้งค่าเบราว์เซอร์ว่าไม่ได้บล็อกการดาวน์โหลด และดูในโฟลเดอร์ Downloads
